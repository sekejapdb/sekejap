# Contract test map

Every numbered rule in `docs/core/GRAPH_CONTRACT.md`, every T1 row in
`docs/lang/QL_CONTRACT.md`, and every section of `docs/dist/OPS_CONTRACT.md`,
mapped to the test file and test name that pins it in this tree, or
`UNPINNED`. Regenerated by reading `core/engine/tests/`, `lang/tests/`,
`dist/tests/`, `dist/rust/tests/` and `dist/ffi/tests/`; every test name
below was checked against a `fn` in one of those files.

T1 means the parser accepts the construct, it compiles to an atomic that
exists, AND a named test proves it. A row that names several constructs is
`UNPINNED` for any construct the tests do not pin.

The language IS built: `lang/` carries the lexer, the parser, the compiler,
`EXPLAIN`, the catalog surface and the refusal table, and `dist/src/pg/`
carries the PostgreSQL wire over them. The older wording of this file --
"there is no SQL parser at HEAD" -- was true of the tree it was written
against and is not true of this one.

T2 rows are listed apart. By the tier's own definition nothing behind them is
built, so there is nothing to pin; a test named against a T2 row pins its
REFUSAL, which is the eighth law holding, not the construct. The counts at
the end keep the two sets apart for that reason.
